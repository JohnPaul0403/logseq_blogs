# Basics of Counting
- Counting it's gived based on statements. Usually is based on 2 rules:
	- **The Rule of Sum**: If a task can be done in M ways and a second task can be done in M ways, therefore this task can be accomplished in M+N times
	- **Pigeonhole Principle**: If m pigeons occupies n pigeonholes and if m > n then at least 1 pigeonhole has 2 or more pigeons on it.
