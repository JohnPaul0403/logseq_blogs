- ## Using Archcraft
- Archcraft is a more more soy version of arch linux where everything you need is already installed out-of-box. The best part of Archcraft is that is highly reliable and it offers a free version with bspwm pre-installed which is similar to I3 style. Currently I am using Archcraft as my main operating system and to be fair it is extremely good and it works extremely fast. The only bad thing about is that it takes a while to boot-up and it allows other apps to use a lot of it's memory. Also since it is out of the box ready with 3 window managers you may find some bugs when using apps meant for other systems.
