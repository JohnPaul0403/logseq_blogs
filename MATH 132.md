- ## Sets
- A set is an unordered collections of distinct objects whereas we create an uncomplex behavior throughout a complex collection of element. Eg:
	- $\{ 1, 3, 5, 7, 9 \} = \{ 5, 7, 3, 9, 1 \}$, though $(1, 2, 3) \ne (3, 2, 1)$
	- **Set Builder**: $\{ X \epsilon \natural | X \text{ is odd and } x < 10 \}$
	- **Natural Numbers**: $\natural = \{ 0, 1, 2, 3, 4, 5 ... \}$
	- **Intervals**: $[ a, b ], (a, b), (a, b]$
	- **Tuples**: A pair of things (a, b) in a ordered fashion.
	- **Set**: A way to define strictly whether or not something belongs to a collection to any element on the universe.
